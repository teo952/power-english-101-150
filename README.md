# Power English 101–150

중2 필수 어휘 Power English 11~15 (No. 101~150) 50단어를 공부하는 웹앱입니다.
iPad Safari에서 링크를 열면 바로 쓸 수 있고, 공유 → "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

- **단어장**: 뜻·발음기호·예문·해석·포인트, 단어/예문 발음 듣기, 뜻 가리기
- **카드**: 영어 먼저 / 뜻 먼저, 밀어서 넘기기, 알아요·몰라요 표시
- **퀴즈**: 영어→뜻, 뜻→영어, 듣고 고르기, 철자 쓰기, 예문 빈칸
- **오답노트**: 틀린 단어 자동 모음, 오답만 카드·퀴즈

발음은 기기에 내장된 영어 음성(Web Speech API)을 씁니다. 학습 기록은 그 기기의 브라우저에만 저장됩니다.
